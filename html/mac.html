Терминал MacOS

  • ls - Вывести список файлов и папок в текущей директории
  • cd - Переместиться между папками
  • win - Вывести текущую рабочую директорию
  • mv - используется для перемещения и переименования файлов и папок
  • mkdir - Создать новую папку в текущей директории
  • echo - Создать новый файл заданного формата
  • less - Посмотреть содержимое файла
  • cp - Скопировать файлы из одной директории в другую
  • rm - Удалить файл
  • rm -r Удалить папку
  • clear - Очистить терминал
